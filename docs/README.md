# Governance Index — Razarth Platform

Este diretório organiza a documentação por função, não por conveniência.

## Estrutura

- `00-VISION/` — visão, norte e estratégia
- `01-ARCHITECTURE/` — arquitetura técnica e estrutura da plataforma
- `02-DOMAIN/` — vocabulário e regras do negócio
- `03-ENGINES/` — motores analíticos e comportamentais
- `04-RFC/` — propostas em discussão
- `05-ADR/` — decisões arquiteturais aprovadas
- `06-ROADMAP/` — sprints e sequência de entrega
- `07-STANDARDS/` — métricas, NFRs e convenções
- `08-DECISIONS/` — decisões operacionais e de produto
- `09-CHANGELOG/` — histórico de mudanças

## Regras

- Se ainda está sendo debatido, vira RFC.
- Se foi decidido, vira ADR.
- Se é limite do sistema, vira standard/NFR.
- Se foi entregue, entra no changelog.
