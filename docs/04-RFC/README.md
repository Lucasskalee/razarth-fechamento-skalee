# RFC — Request for Comments

Use RFC quando uma mudança ainda não está decidida e precisa de debate formal.

## Quando abrir uma RFC

- mudar um padrão arquitetural;
- alterar comportamento de multi-tenancy;
- introduzir uma tecnologia nova;
- remover algo de `NON_GOALS.md`;
- discutir impacto de performance, segurança ou escalabilidade.

## Estrutura sugerida

1. Contexto
2. Problema
3. Alternativas
4. Recomendação
5. Impacto
6. Decisão

## Regra

RFC não é documento decorativo. Se não houver decisão, a proposta continua aberta.
