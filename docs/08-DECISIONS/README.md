# Decisions — Razarth Platform

Esta pasta registra decisões já tomadas fora do nível da arquitetura base.

## Use para

- decisões de produto;
- decisões de rollout;
- decisões operacionais;
- decisões que não precisam virar ADR, mas precisam ficar rastreadas.

## Relação com ADR

- **ADR**: decisão estrutural e arquitetural.
- **Decision**: decisão contextual de execução.

## Regra

Se a decisão muda a forma do sistema, ela precisa aparecer aqui ou em ADR.
