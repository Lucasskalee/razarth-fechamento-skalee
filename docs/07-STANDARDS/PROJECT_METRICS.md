# Project Metrics — Razarth Platform

## KPIs de Engenharia

| Indicador | Meta |
| --- | --- |
| Cobertura de testes | > 85% |
| ADRs documentados | 100% das decisões arquiteturais |
| RFCs aprovadas | 100% dos módulos grandes |
| Código duplicado | < 3% |
| Tempo médio de build | < 3 min |
| Tempo médio de análise | < 2 s |
| Bugs críticos por sprint | 0 |

## Regras

- Métrica sem ação não serve.
- Métrica fora da meta gera revisão técnica.
- Métrica boa deve permanecer visível no CI e no roadmap.
